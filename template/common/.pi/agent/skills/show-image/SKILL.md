# Показ картинок в pi-web-ui

В веб-интерфейсе (pi-web-ui) показать картинку пользователю можно только
markdown-изображением в тексте ответа. Тул-карточка `read` юзеру картинку
не показывает (только агенту), rawHtml выключен, у `.md img` нет max-width —
поэтому большие картинки дают горизонтальный скролл, а путь к файлу в `src`
надо указывать готовым URL.

## Как показывать

Выполни (скрипт лежит рядом с этим скиллом):

```bash
~/.pi/agent/skills/show-image/imgfit <оригинал> [макс-ширина=800]
```

и вставь его вывод в ответ **ДОСЛОВНО** — это критично. Первая строка вывода —
напоминание об этом; markdown-ссылка и подпись уже финальные: путь в ссылке
собран самим скриптом (превью из `/tmp/imgfit` или сам оригинал, если он уже
не шире лимита). НИКОГДА не конструируй путь сам и не добавляй суффиксы вида
`-w800` по памяти — источник реального сбоя: скрипт вернул оригинал, а агент
вставил выдуманный путь `…-w900.jpg`, которого не существовало → битая картинка.

`imgfit`:

- кладёт уменьшенную копию-превью в `/tmp/imgfit/` — вне workspace,
  артефактов в проекте нет; `/tmp` очищается при перезапуске контейнера;
- если оригинал уже ≤ лимита — ссылка ведёт на оригинал, в подписи пометка
  «превью: оригинал (уже ≤ лимита)»;
- сам проверяет ссылку через webui-сервер (`/api/file`, `Content-Type:
  image/*`); если сервер не запущен или ответ не картинка — предупреждение в
  stderr: вставляй, но скажи юзеру, что webui надо запустить;
- валидирует вход: не-картинка и отсутствующий файл — внятная ошибка;
- при первом запуске сам создаёт venv `~/.pi/agent/venv-img` с Pillow
  (~15 с, нужна сеть) — python3 уже в образе.

## Почему именно так (механика pi-web-ui)

- `/api/file?path=<абсолютный путь>` — единственный эндпоинт, раздающий файлы
  **вне workspace** (у `/api/preview` containment-проверка hardcoded, настроек
  отключения нет).
- Оригиналы не трогаем и не копируем в workspace — они лежат там, где лежат
  (например `~/.pi/images` — дефолтный outputDir pi-image-gen).
- Превью ≤800px, т.к. вьюпорт узкий и у `.md img` нет max-width.
- В TUI ссылка деградирует в текст — это приемлемо (скилл только для web-ui).
