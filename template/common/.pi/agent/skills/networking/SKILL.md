# Сеть в pibox

## Топология

- Контейнер: eth0 172.17.0.x (docker bridge).
- Хост-машина из контейнера: `host.docker.internal` (добавлен через --add-host).
- Хост видит контейнер только на опубликованных портах: `pibox -p HOST:CONT`.

## Dev-серверы

- Слушать `0.0.0.0`, НЕ `127.0.0.1` — иначе сервер недоступен даже через
  опубликованный порт.
- **Порт 3000 зарезервирован под dev-серверы и проброшен по умолчанию**:
  поднимай серверы именно на нём. Хост-порт — в переменной
  `$PIBOX_DEV_PORT` (обычно 3000; пользователь мог замапить иначе,
  например `-p 8080:3000` — тогда 8080). Переменной нет — проброса нет,
  попроси пользователя перезапустить с `-p ХОСТ:3000`.
- Другой порт тоже можно, но тогда нужен явный `pibox -p HOST:CONT` при
  запуске (флаг ты не контролируешь) — просто оставайся на 3000.
- Привилегированные порты (<1024): на части хостов bind на них работает
  (docker с `ip_unprivileged_port_start=0`, например Docker Desktop), на
  обычном Linux — нет (CAP_NET_BIND_SERVICE сброшена). Не полагайся на низкие
  порты — внутри контейнера слушай ≥1024, наружу мапится любой (`-p 80:8080`).
- Пример: `uvicorn --host 0.0.0.0 --port 3000` → на хосте
  `localhost:$PIBOX_DEV_PORT`.

## К хост-сервисам из контейнера

- Локальная модель API, БД и т.д. на хосте: `http://host.docker.internal:PORT`
- `localhost` внутри контейнера — это САМ контейнер, не хост.

## Инструменты

- Есть: `curl`, `wget`, `dig`, `nslookup`, `ss`, `ping`. Нет: `nc`, `telnet`, `traceroute`.
- Проверить порт без nc: `(echo >/dev/tcp/host/port) 2>/dev/null && echo open`
- Что слушает процесс: `ss -tlnp`

## Диагностика «порт не открывается»

1. `ss -tlnp` — слушает ли вообще, на каком адресе (0.0.0.0 vs 127.0.0.1).
2. Публикация порта (`-p`) — без неё хост порт не увидит. Флаг запуска ты
   не контролируешь: назови пользователю нужный `pibox -p HOST:CONT` и попроси
   перезапустить.
3. Файрвол хоста — вне твоего контроля, сообщи пользователю.

## Прочее

- DNS — встроенный резолвер Docker; `/etc/resolv.conf` трогать не надо.
- Интернет открыт, если хост не ограничил.
