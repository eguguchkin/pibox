# template/ — двухслойный шаблон окружений

Каталоги этого дерева применяются к `PIBOX_DIR/env/<name>` (будущему
`/home/pi` в контейнере) в момент создания окружения и при каждом запуске.

## Слои

| | `common/` | `user/` |
| --- | --- | --- |
| Смысл | продукт: начальное состояние окружения | личные инварианты владельца |
| Смысл | продукт: начальное состояние окружения | личные инварианты владельца |
| Применяется | один раз, при `pibox env create` | при каждом запуске `pibox`/`shell`/`webui`/`tg` |
| Кто пишет | `install.sh` (перезаписывается всегда) | владелец на хосте и `pibox user pull` |

Правила:

- `common` задаёт стартовое состояние: `.pi/agent/AGENTS.md` (инструкции
  агента о контейнере), скиллы (`workspace-hygiene`, `install-languages`,
  `networking`, `extension-hygiene`, `show-image`), расширения
  `terminal-probe`.
- `user` — то, что должно переживать пересоздание окружения:
  `models.json` (ключи провайдеров), `USER.md` (личные инструкции),
  личные расширения и конфиги (`selectel-thinking-off.ts`,
  `pi-image-gen/settings.json`, `telegram.json` — токен Telegram-моста,
  заглушка REPLACE_ME), `.bashrc.user`. Файлы из `user`
  копируются в окружение при каждом запуске — правки на хосте доходят
  автоматически. Файл из `user` с тем же путём перекрывает `common`.
- Окружение — не производная: сессии, память, доустановленные расширения
  и бинари накапливаются в нём и не удаляются применением слоёв.
  `common` — начальное состояние, `user` — инварианты, остальное — жизнь.
- Память агента (`memory/`) в слоях не участвует — она живёт только в env.

## Манифест расширений

`extensions.txt` (рядом с этим README) — эталонный набор расширений pi
(`npm:имя@версия`), ставится командой `pibox extensions install [-e ИМЯ]`.
Установщик разрешает install-скрипты npm-пакетов переменной окружения
(npm 11.19+ по умолчанию их молча пропускает); ручной `pi install`
в окружении остаётся под гейтом — см. docs/PROJECT.md.
Личных манифестов нет: расширения, поставленные вручную (`pi install`),
живут в окружении и при пересоздании не восстанавливаются.

## Секреты

В репозитории `template/user/` хранятся заглушки (`REPLACE_ME`,
`$SELECTEL_API_KEY`). Реальные значения правятся в каталоге установки
(`$PIBOX_DIR/template/user/`) после `install.sh` — там же живут ключи,
и это не репозиторий.

## Команды

```text
pibox user push      # применить template/user к окружению (как при старте)
pibox user pull      # сохранить правки агента из окружения в template/user
pibox user pull PATH # то же для конкретного файла (даже нового)
```

Точечные dot-файлы (`.bashrc`, `.profile`, …) добавляет entrypoint из
`/opt/skel` образа; `.bashrc.user` из слоя `user` доезжает до контейнера
и подмешивается entrypoint'ом.
